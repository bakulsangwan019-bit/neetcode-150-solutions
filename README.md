# NeetCode 150 — 90 Day DSA Challenge

I’m working through the NeetCode 150 roadmap in Python as a 90-day challenge.

The goal is not just to collect 150 accepted solutions.

My goal is to understand how data moves through the program, why a particular approach works, what information needs to be stored, and how different data structures and algorithms change the efficiency of a solution.

## My Learning Process

For each problem, I try to solve it myself first.

After my attempt, I may use ChatGPT as a learning and review tool to:

- Question why each part of my solution is needed
- Evaluate how values and data move through the algorithm
- Compare my approach with other possible approaches
- Understand time and space complexity
- Find weaknesses or edge cases in my reasoning
- Improve comments and repository documentation

The code in this repository is meant to represent solutions that I have worked through and understood, rather than simply copying generated answers.

When multiple approaches are included, they are there to help compare how the solution evolves from a simpler idea to a more efficient one.

## Why I’m Documenting This

I want this repository to be more than a collection of answers.

I’m using it as a learning record for understanding:

- How data is manipulated internally
- Why pointers, windows, sets, dictionaries, and other structures move or change
- Why one approach is more efficient than another
- Time and space complexity
- Patterns that can be reused in future problems

If you’re learning DSA too, feel free to use the repository as a learning and comparison resource.

Try the problem yourself first, then compare your reasoning with the approaches here.

## The 90-Day Challenge

**90 days. 150 problems. One rule: understanding > memorizing.**

A problem is not finished for me just because it gets Accepted.

I want to be able to explain:

- Why the approach works
- Why the chosen data structure fits
- Why each important condition exists
- How the data changes while the algorithm runs
- What the time and space complexity are
- What pattern I should recognize when I see a similar problem again

If you’re working through NeetCode 150 too, take the challenge with me.

Solve it. Explain it. Compare it. Improve it.
