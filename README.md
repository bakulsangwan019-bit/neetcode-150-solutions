# NeetCode 150 — 90 Day DSA Challenge 🚀

I'm working through the **NeetCode 150 roadmap in Python** as a 90-day challenge to strengthen my understanding of Data Structures, Algorithms, problem-solving patterns, and complexity analysis.

The goal is **not just to get 150 accepted solutions**.

For every problem, I want to understand:

- Why the approach works
- Which data structure fits the problem
- How the solution can be improved
- Time complexity
- Auxiliary / space complexity
- The pattern I should recognize when I see a similar problem again

## 🧠 How I Approach Problems

Instead of trying to memorize solutions, I try to ask:

**What information do I need?**

↓

**What do I need to store or check?**

↓

**Which data structure fits that job?**

↓

**Can I avoid repeated work?**

↓

**What is the time and space complexity?**

Where useful, I also keep multiple approaches so I can see how a solution improves from a simpler method to a more efficient one.
